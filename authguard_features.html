LOGIN THREAT SCANNER

Input Interface Features

What users enter into the AuthGuard scanner to trigger an AI-powered threat analysis.

🌐

SOURCE IP ADDRESS

Manually enter any IPv4 address. AuthGuard checks it against a known malicious IP database and flags public DNS resolvers (8.8.8.8, 1.1.1.1) as suspicious. Known bad IPs like 45.33.12.99 instantly raise the threat score by +40.

🔑

AUTHENTICATION METHOD

Select from three methods: Password (weakest — triggers extra score on failure), MFA (strong — multi-factor authentication), or SSH Key (secure — key-based authentication). Each method contributes to the risk profile.

🚦

LOGIN STATUS

Select SUCCESS or FAIL. A failed login immediately adds +20 to the threat score. Combined with high failure count and a weak auth method, this is a strong brute-force indicator.

🔢

FAILURE COUNT SLIDER

Slide from 0 to 20 to indicate how many failed login attempts have occurred from this IP in the last 24 hours. 0 failures = clean. 4–9 = elevated risk (+12). 10+ = brute-force zone (+25), one of the strongest threat signals.

👤

USERNAME TYPE

Choose Regular User or Admin / Root. Admin/root account access adds +10 to the threat score — privileged accounts are high-value targets and any suspicious activity on them is treated as a priority threat.

📋

RECENT SCANS HISTORY

The last 5 scans are automatically saved and displayed in the UI with timestamp, source IP, and threat score. Color-coded green (normal) or red (abnormal) for instant visual reference — no need to re-scan known IPs.

AI DETECTION ENGINE

Dual Machine Learning Models

AuthGuard runs two ML models simultaneously and blends their scores for maximum detection accuracy.

🌲
ISOLATION FOREST — UNSUPERVISED

Detects statistical outliers without needing any labels. Builds 150 random decision trees across all features. Short isolation path = easy to separate = ABNORMAL.

▸ 150 estimators for robust detection
▸ Contamination parameter: 15% sensitivity
▸ Works without labels — detects zero-days
▸ Score normalized 0 → 1 after prediction
🌳
RANDOM FOREST — SUPERVISED

Trained on labeled login data to classify NORMAL vs ABNORMAL. 100 decision trees with balanced class weights handle dataset imbalance automatically.

▸ 100 trees, class_weight='balanced'
▸ Outputs probability score 0.0 → 1.0
▸ Feature importance reveals key signals
▸ High precision on labeled login data
⬡
ENSEMBLE FUSION FORMULA
Threat Score = (Isolation Forest score × 0.5) + (Random Forest probability × 0.5)
Score ≥ 35 → 🚨 ABNORMAL  |  Score < 35 → ✅ NORMAL

FULL DASHBOARD

Flask-Powered Analytics Dashboard

The AuthGuard dashboard processes your entire dataset and displays rich threat intelligence visualizations.

📂
FILE UPLOAD
Upload your own .xlsx or .csv login dataset. AuthGuard auto-detects columns and engineers features. Also includes built-in demo data — works instantly with zero setup.
🎛️
MODEL SELECTOR
Choose between Isolation Forest (unsupervised), Random Forest (supervised), or Both for the ensemble approach. Switchable at any time without reloading.
🎚️
SENSITIVITY SLIDER
Adjust the contamination parameter from 1% to 40% in real-time. Lower = more strict (fewer detections), Higher = more sensitive (catches more threats). Fine-tune to your dataset.
📊
5 STAT CARDS
Animated live counters: Total Logs, Normal Count, Threats Found, Model Accuracy, and ROC-AUC Score. Numbers animate up on each analysis run.
🍩
DOUGHNUT CHART
Visual split of NORMAL vs THREAT proportions across your entire dataset. Interactive tooltips show exact counts on hover.
📉
THREAT TIMELINE
Dual-axis line chart showing threat rate % and event count over time. Auto-adjusts to daily or hourly based on your dataset's time span.
🗺️
TOP SUSPICIOUS IPs
Horizontal bar chart ranking the top 8 most threat-associated IP addresses in your dataset. Instantly spot repeat offenders.
📋
LOGS TABLE
Full paginated table — 15 records per page — with color-coded threat score bars per row. Threats appear at the top, sorted by score descending.
🔍
SEARCH & FILTER
Live search by IP, username, or auth method. Filter tabs: All Logs, Threats Only, Normal Only. Results update instantly with no reload.
